## ✨ Overview

**Navexa WMS** is a warehouse management and automation platform designed to connect physical warehouse operations with real-time digital-twin visualization. By combining interactive floor-plan tracking, autonomous guided vehicle (AGV) monitoring, and live logistics dispatch controls, the platform gives operators a clearer view of warehouse activity and robotics fleet performance.

I conceptualized and built the interactive web workspace for Navexa WMS, replacing rigid tabular layouts with a schematic floor-plan interface that visualizes robot routes, battery telemetry, and charging stations. Complemented by responsive glassmorphism drawers and modular operational analytics, the experience makes complex warehouse workflows more intuitive, accessible, and efficient.
